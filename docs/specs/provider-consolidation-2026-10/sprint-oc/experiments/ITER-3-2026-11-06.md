## The four owner questions, Deep Agents (from this run)

- **Capabilities:** MCP servers, tools and skill bundles bind through launch bindings; hook scripts, plugins and context
  bundles have no Deep Agents launch binding (`adapters/deep_agents/compile.py`). Every stage got 7 filesystem tools plus
  `submit_output`.
- **Temporal shape and replay:** run workflow -> family workflow (`belllabs.stagegraph`) -> one `OperationWorkflow` child
  per stage attempt -> `lane.turn` activity, with LangGraph checkpoints inside the activity. Three replays exist: Temporal
  history replay (`Replayer`, used only in determinism tests), point-level time travel (state-as-of R3, fork from a point) and
  `run replay --dry-run` (rebuilds a step's model input from the transcript; exact on this run).
- **Inspection:** `run inspect`, `run points`, `run state-as-of`, `run transcript` and `run replay` answered lifecycle,
  timing, seed and input questions; failure causes of the derived run did not (F1-G5).
- **Fork:** the fork may carry a message (inline text or one content ref with a media type), an instruction, changes on the
  workflow type's declared patchable paths, the position, the invalidation frontier and baseline reservations; capability grants,
  budget ceilings, authority and the workflow type are protected (REQ-CP-EXEC-012), so new MCP servers or skills on a fork are
  refused by design.
