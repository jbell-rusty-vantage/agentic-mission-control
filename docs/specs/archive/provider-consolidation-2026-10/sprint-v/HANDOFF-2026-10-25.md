## 5. Traps learned this session

- Knowledge Services: run `corepack pnpm` from PowerShell; Biome writes CRLF; the lint ratchet allows zero new
  diagnostics; the `.agent-docs` semantic map has a byte budget (now 160 KiB) and every `packages/*` directory must be
  mapped in `.agent-docs/modules.json`; component migrations never contain `BEGIN`/`COMMIT` (the installer wraps them).
- Mission Control: `.venv/Scripts/*.exe`, never `uv run`; several source files are CRLF; `tests/fixtures/mission_control_common_db.py`
  installs the newest built release (1.5.0 now).
- BKS: unit tests that load the absent `../biotech-meta` fail before and after this work; integration files must run
  sequentially against the shared test Neo4j.
- Bash heredocs containing a single quote inside a triple-quoted Python string break; write helper scripts to the
  scratchpad and run them.
