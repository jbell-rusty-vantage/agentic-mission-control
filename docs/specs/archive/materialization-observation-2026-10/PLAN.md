## Verification rules (from AGENTS.md)

- Run `make check`, or `uv run ruff check .`, `uv run mypy` and the relevant `uv run --group biotech pytest` selections, for every issue.
- Persistence and runtime claims use **real local PostgreSQL and Temporal**. Remote claims (R, S2, S3) also cite the AWS task's logs and the Temporal Cloud workflow ids.
- Report passed, failed, blocked and unrun checks separately.
- Common SQL changes go only through `packages/mission-control-db-contract`, in the allocated slots 0035 to 0040.
- The domain layer imports no provider SDK. Adapters implement ports; bootstrap wires them.
- **Every lane passes the lane conformance suite (HL-05) before merging.** `qualified` flips only on recorded live evidence for that exact profile and placement.
- The LS skills import nothing from `mission_control` and pass offline with the fake-CLI harness.
- Authorization boundaries are in [TEAM-WORKSPACE](TEAM-WORKSPACE.md#authorization-boundaries-from-the-owner-as-of-2026-10-12). Pre-approved:
  - the Vercel deployment of the ingress and launch route;
  - the AWS resources and deploys named in SPEC-11 §4, inside the $40/month budget;
  - the live 1.4.0 migration after local proofs;
  - paid drills within each slice's $10 budget.
