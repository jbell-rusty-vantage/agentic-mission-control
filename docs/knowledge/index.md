# Mission Control knowledge

Concepts explain how the code realizes the decisions: one concept per file, each citing source and tests, grouped by category. The code is what runs, the ADRs (docs/adr) are what was decided, the concepts explain both, and the program ledgers (docs/specs) are working documents. This file is generated by docs/tools/agents_docs_index.py from the concept frontmatter; each line is the concept's first question.

Every concept answers, where it applies, scheduling, output contract obligations, context transfer, and agent runtime and capability configuration, and ends with a Built / specified / goal line. Search: python docs/tools/okf_search.py; the update history is log.md.
