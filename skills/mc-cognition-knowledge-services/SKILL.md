# knowledge-services

Use only the application admitted Knowledge Services MCP capability selected by an exact manifest pin. If no binding is installed, report the missing prerequisite; never invent an endpoint or credentials. Request typed acquisition, inspection, preparation, verification and retrieval operations within the mission grants. Emit artifact.ready through signal_emit or mc-signal after registering the report output; execution completion is not mission acceptance.
